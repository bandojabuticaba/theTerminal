# The Terminal

The Terminal is a detective puzzle game where you don't type code, you build it. Sitting at a retro CRT workstation, you drag commands, flags, and clues pulled straight out of the files you read into a command line, executing real Unix-style syntax to crack open a hidden system and uncover the story buried inside it.

It plays with the same "assemble the solution" satisfaction found in other deduction puzzle games like The Case of the Golden Idol, filtered through a tactile hacker-fantasy atmosphere and a mystery uncovered purely through environmental storytelling, without ever requiring the player to know how a terminal actually works.

**Target audience:** puzzle and mystery fans primarily, narrative-adventure and "hacker fantasy" players secondarily. Explicitly not a programming-education tool.
